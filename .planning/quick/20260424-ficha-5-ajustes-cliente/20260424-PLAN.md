  ```tsx
  <TextField
    fullWidth
    size="small"
    label="Cod."
    value={itemOptions.find((i) => i.id === row.itemId)?.code ?? ""}
    onChange={(event) => {
      const nextCode = event.target.value.trim();
      if (!nextCode) return;
      const match = itemOptions.find(
        (i) => (i.code ?? "").toLowerCase() === nextCode.toLowerCase()
      );
      if (match) {
        onUpdateRow(index, {
          itemId: match.id,
          usageUnit: match.usageUnit ?? row.usageUnit,
          componentType:
            match.type === "embalagem" ? "embalagem"
            : match.type === "apoio" ? "apoio"
            : "ingrediente"
        });
      }
    }}
    slotProps={{ htmlInput: { style: { fontSize: 11 } } }}
  />
  ```
  - Controlled via lookup do item atual para exibir; onChange busca match por code.
  - Value sempre reflete `code` do item selecionado; quando o usuário digita, se tem match preenche o item. Se não, visualmente o code exibido volta ao do item no próximo render (sem estado transiente é ok para quick).
  - Se quiser um local state para permitir digitação parcial sem perder foco, usar `useState` local dentro de uma sub-component. Simplificar: usar um controlled-from-input com re-render controlado.
  - **Implementação prática:** criar um pequeno subcomponente `CodeInput` que guarda texto local até blur/Enter, aí resolve. Mais UX-friendly.
