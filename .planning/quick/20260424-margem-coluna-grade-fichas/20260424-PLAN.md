# Quick Task: Coluna Margem na grade de Fichas Técnicas

## Contexto

Cliente pediu (print #2 com referência app.custoderreceita.com.br/cardapio) uma coluna MARGEM visual na grade `/fichas`, com barra horizontal colorida + percentual, posicionada após PRECO DE VENDA. O dado já é calculado no detalhe da ficha no quadro "Venda e Margem" (simulador em tempo real) — precisa ser exposto no mapper do list.

## Design contract (lock)

**Fonte autoritativa:** `src/modules/engineering/ui/TotaisIndicadores.tsx:388-433` (`MargemBar`).

| Range | Cor | Token |
|-------|-----|-------|
| `mc > 60%` | Verde | `#1B6B2C` |
| `35% ≤ mc ≤ 60%` | Ambar | `#854F0B` |
| `mc < 35%` | Vermelho | `#A32D2D` |
| `null` (sem PV ou sem despesaVariavel) | Cinza muted | `#888780` |

- Bar: bg `#D3D1C7`, altura 4px, border-radius 2px (mesmo do detail)
- Fill animado? Não — grade estática, evitar transições.
- Label: percentual arredondado (`toFixed(0)`) à direita do bar, cor = mesma do fill (reforço visual).
- Null state: bar vazio (0% width) cinza + texto `--` cinza `#888780`.

## Cálculo (paritário com detail)

```ts
const salePrice = Number(record.precoVenda ?? 0);
const totalInputCost = Number(costs.total);
const packagingCost = Number(costs.packaging);
const costReal = totalInputCost + packagingCost;
const variableExpensePercent = normalizePercentInput(
  record.despesaVariavelPercentual ? Number(record.despesaVariavelPercentual) : null
);
// null se qualquer operando ausente → exibe "--" na grade
const marginPercent =
  salePrice > 0 && variableExpensePercent !== null
    ? (salePrice - costReal - salePrice * variableExpensePercent) / salePrice
    : null;
```

Retorno como string escala 0-1 (ex: `"0.8177"`), matching `formatOptionalMetric`. `null` quando indefinido.
