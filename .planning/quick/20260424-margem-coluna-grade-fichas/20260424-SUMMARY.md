# Quick Task 20260424 — Coluna Margem na grade de Fichas Técnicas

## Resultado

Nova coluna **Margem** na listagem `/fichas`, posicionada entre `Preco de Venda` e `Ult. Atualizacao`. Cada linha mostra bar horizontal (54×4 px) + percentual à direita, com cor conforme thresholds idênticos ao `MargemBar` da tela de detalhe. Null state (sem preço de venda ou sem despesa variável persistida) exibe `--` em cinza.

## Design contract

Fonte autoritativa: `src/modules/engineering/ui/TotaisIndicadores.tsx:388-433` (`MargemBar`).

| Range | Cor | Token |
|-------|-----|-------|
| `> 60%` | Verde | `#1B6B2C` |
| `35%-60%` | Ambar | `#854F0B` |
| `< 35%` | Vermelho | `#A32D2D` |
| `null` | Cinza | `#888780` |

Bar: bg `#D3D1C7` (BORDER), altura 4px, border-radius 2px. Label percentual `toFixed(0)` + `%` na mesma cor do fill.

## Cálculo (paritário com buildFichaIndicators)

```ts
salePrice > 0 && variableExpensePercent !== null
  ? (salePrice - (totalCost + packaging) - salePrice * variableExpensePercent) / salePrice
  : null
```

`normalizePercentInput` reaproveitada (já existe na repository, linha 102) para converter "15" → 0.15 quando necessário.
