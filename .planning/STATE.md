## Blockers/Concerns

- Risco estrutural conhecido: repositorios com caminho duplo Prisma/demo podem divergir de comportamento entre ambientes.
- Observacao operacional: a importacao recorrente usa mapeamento automatico das colunas conhecidas; se o layout do CSV variar muito, a proxima evolucao natural e um mapeador manual assistido.
- Observacao tecnica: os testes de integracao/E2E dependem de `DATABASE_URL` configurada e de um Postgres disponivel via Docker Compose.
- Tensao de arquitetura para a Phase 7: o PDF pede `Produto` livre na ficha, enquanto o repositorio exige item mestre canonico; o plano registrado resolve isso com nome livre na UI e vinculo tecnico preservado no backend.
- Tensao funcional nova: o PDF mais recente redefine a leitura de `FC/IC` e amplia o Quadro Final; o planejamento foi corrigido para que a execucao nao replique a formula anterior por engano.
