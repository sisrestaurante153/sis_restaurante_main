## Architecture decisions

- **B3 — State lift:** ComponentsEditor aceita props opcionais `hideQuadroFinal`, `onQuadroFinalChange`, e controladores externos (`salePriceInput`, `variableExpensePercentInput`, `assemblyEnabled` + respectivos `onChange`). Quando `hideQuadroFinal=true`, ComponentsEditor renderiza `<QuadroFinalPublisher>` que publica snapshot via `useEffect(serialized)`. Ficha-form consome o snapshot e renderiza `<TotaisIndicadores>` apos `<FormSection title="Finalizacao">`. Mutacoes no TotaisIndicadores fluem de volta para ComponentsEditor via os setters controlados. Padrao permite rollback facil (ComponentsEditor continua standalone quando chamado sem essas props).
- **B4 — Tokens inline:** `TOKENS` object centraliza hex tokens que batem 1:1 com `--verde`, `--ambar`, `--azul`, etc. do HTML v2 (linha 121-210). Layout usa `Box sx` com grid/flex nativos, sem MUI `Paper`/`Grid`/`Divider` (pra controlar spacing pixel-perfect). Componentes auxiliares: `HsItem`, `QfRow`, `QfCard`, `MontagemToggle`, `CmvHealthBadge`, `MargemBar`, `LoCell`. Inputs inline no card "Venda e Margem" usam `<Box component="input">` com `type="text" inputMode="decimal"` para preservar `toHaveValue("")` em tests.
